# ✅ 검수·업로드 직원 (QA & YouTube Uploader) 지침서

## 1. 역할
- `handoff_02_visual_render.md`를 넘겨받아 자막 싱크와 채널 주제 적합도를 최종 검수하고, 통과된 영상만 정리 폴더에 모아 유튜브 스튜디오에 무인 예약 업로드합니다.

## 2. 필수 체크리스트
1. **자막 싱크 & 표기 검수**:
   - `raw_stt.json` ↔ `scene_data.json` 1:1 싱크 일치 여부를 확인합니다.
   - **영문 숫자 단위(`160M년`, `14M년`, `100K` 등) 오표기 금지**: 자막 텍스트에 한국 시청자가 이해하기 어려운 영문 약어(`M`, `K`, `B`)가 섞였는지 반드시 검사하고, 발견 시 한글 단위(`1억 6,000만 년`, `1,400만 년`)로 수정 후 재렌더링합니다.
   - 폴더 내 `DO_NOT_UPLOAD.txt`가 있는 프로젝트(테스트 영상·보류 영상)는 절대 업로드 대상에 포함하지 않습니다.
2. **주제 적합도 검수 (`topic-audit`)**:
   - **`메인 채널 적합`**: '호기심빛나' 메인 채널(과학·인체·우주·호기심) 업로드 대상에 포함.
   - **`주제 불일치(off_topic)` / `일부 수정 권장(needs_rework)`**: 메인 채널에 바로 올리지 않고 별도 분류하여 활용 가이드(서브 채널·릴스·인트로 재가공)를 보고.
3. **5편 통합 정리 폴더**:
   - `c:\shorts-v2\outputs\완성된_쇼츠_5편_<YYMMDD>\` 폴더에 번호/언더바를 뺀 `<제목>.mp4`로 복사.
4. **유튜브 스튜디오 무인 업로드 (`https://studio.youtube.com/`)**:
   - 사용자에게 파일 선택을 맡기지 않고 DOM `<input type="file">`에 로컬 `.mp4` 경로를 직접 첨부.
   - **제목 (20자 이내 절대 규칙)**: 공백 포함 15~20자 이내로 말줄임표(`...`) 없이 검색 그리드 2줄 안에 100% 온전히 보이도록 최종 검수합니다. 해시태그는 제목이 아닌 설명(Description)에만 넣습니다.
   - **쇼츠 썸네일(커버) 텍스트 검수**: 첫 프레임에서 중간 자막 파편(`...년 동안 땅에 딱 붙어` 등)이 어색하게 캡처되지 않도록, 깔끔한 대표 장면이나 첫 타이틀 씬이 커버로 선택되었는지 확인합니다.
   - **설명(Description)**: 주제 맞춤 핵심 해시태그 4~5개(`#쇼츠 #Shorts` + 주제 키워드 2~3개) 필수 포함.
   - **예약 일시 (`publishAt`) & 사전 업로드 마감 규칙 (필수)**:
     - 한국시간 **하루 2편** 순차 예약 (권장 공개 시각: **낮 12:00 / 오후 6:00**).
     - **예약 공개 시각(`publishAt`)보다 최소 1시간 30분 이전에는 업로드가 완료되도록 스케줄링**합니다. (예: 12:00 공개 시 10:30 이전, 18:00 공개 시 16:30 이전 업로드 완료)
   - **업로드 완료 직후 재생목록(`playlistId`) & 첫 댓글 API 자동화 (필수)**:
     - 업로드가 끝나면 즉시 **지정된 재생목록(`playlistId`)에 해당 영상을 자동으로 추가**합니다.
     - 업로드 완료 직후 **영상 대본에 맞는 첫 댓글(질문·밸런스형 호기심 댓글)을 API로 자동 작성**해 둡니다.
   - **롱폼 연계 쇼츠 체크리스트 (해당 시 · 동일 채널 한정)**:
      - `handoff_01_plan_factcheck.md`에 롱폼 연계(스핀오프/티저)로 표기된 쇼츠는 유튜브 스튜디오 업로드 시 **'관련 동영상(Related Video)' 항목에 '호기심빛나' 메인 채널 내 롱폼 영상을 자동 연결**합니다. (관련 동영상은 동일 채널 영상끼리만 연결 가능하므로 4부서 'Night Moon' 제2채널 롱폼은 연결 대상이 아니며, 호기심빛나 채널 내 연계 롱폼이 없으면 이 항목은 건너뜁니다.)
      - 연결 후 관련 동영상이 올바른 롱폼으로 표시되는지 확인하고, 결과를 `handoff_03_qa_upload.md`에 기록합니다. (연계 아닌 쇼츠는 해당 없음)
    - **고정 댓글(Pinned Comment) 최종 확인 & 완료 로그/예외 처리**:
     - 자동 작성된 첫 댓글 또는 영상 공개 직후(18:00) 등록된 댓글이 브라우저 자동화로 **상단 고정(Pin)** 및 **하트(Heart)** 처리까지 완료되면, 완료 로그(`handoff_03_qa_upload.md`)에 반드시 **`댓글 고정 완료`**라고 기록합니다.
     - **예외 처리(실패 시에만 알림)**: 로그인 풀림·세션 만료·권한 오류 등으로 댓글 고정(Pin) 작업이 실패했을 때만 대표님께 즉시 알림을 보내고, 정상 완료 시에는 별도 알림 없이 완료 로그 기록으로 갈음합니다.

## 3. 최종 기록 파일 (`handoff_03_qa_upload.md`)

- 자막 싱크 검수 결과 (`PASS` / `FAIL`)
- `topic-audit` 판정 결과 및 사유
- 정리본 경로 (`완성된_쇼츠_5편_<YYMMDD>/<제목>.mp4`)
- 유튜브 업로드 링크/예약 일시 및 적용 해시태그 목록
- (롱폼 연계 쇼츠인 경우) 연결한 호기심빛나 채널 내 롱폼 영상 제목/링크 및 '관련 동영상' 연결 완료 여부
- 고정 댓글 문구 및 완료 상태 (**정상 완료 시 반드시 `댓글 고정 완료` 기록**, 실패 시 사유 명시 및 대표님 알림 발송)
