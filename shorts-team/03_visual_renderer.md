# 🎨 비주얼·렌더링 직원 (Visual & Renderer) 지침서

## 1. 역할
- `handoff_01_plan_factcheck.md`가 통과된 대본을 받아 음성(TTS) 생성 → Google Flow 씬 이미지 생성 → 최종 9:16 쇼츠 영상 렌더링까지 완료합니다.

## 2. 필수 체크리스트
1. **7단계 음성(TTS) 생성 & 나레이션-자막 싱크 표준 파이프라인 (쇼츠팀 전용)**:
   - **대본 2종 지원**: 프로젝트 폴더에 `tts_script.md`(한글 발음 표기)와 `subtitle_script.md`(원래 숫자·영문 표기)가 있으면 각각 TTS 생성과 자막 교정에 우선 적용하고, 없으면 기존 `final_script.md`를 그대로 사용합니다.
   - **배속 선적용**: TTS 생성 직후 최종 배속(`1.2x`) 변환을 먼저 끝낸 `output_1.2x.wav` 기준으로 STT와 렌더링을 진행해 배속 계산 오차를 제거합니다.
   - **Whisper STT + LLM 1:1 교정 안전장치**: `whisper-1` (`verbose_json`, `segment`) 타임스탬프를 고정한 채 `gpt-4o-mini` (`temperature=0.0`)로 숫자·영문·오타만 미세 교정합니다. 문장 병합·누락(글자 수 변화율 `0.55~1.85배` 이탈)이나 환각(원본 문자 중복률 `40% 미만`)이 감지되면 원본 STT를 자동 유지하며, 숫자·영문 치환(`"칠십 퍼센트"→"70%"`, `"에이아이"→"AI"` 등)에는 예외 보정을 적용합니다.
   - **쇼츠 1줄 분할 + 24fps 합성**: 16자 초과 문장은 8~15자 1줄 청크로 균형 분할 및 공백 제외 음절 비례 시간 배분 후, Remotion 24fps 타임라인에서 프레임 단위로 합성합니다.
2. **이미지 매칭 & 씬 개수 최적화 (15% 축소 규칙)**:
   - 대시보드에서 **전체 매칭: 전체/일부 OFF** 상태로 설정합니다.
   - **이미지(씬) 수 약 15% 축소**: 기존 40초 영상 기준 11~15장(평균 2.7~3.5초/장)으로 이미지가 너무 빠르게 지나가는 문제를 방지하기 위해, **편당 고유 이미지 수는 8~10장으로 유지**합니다. 단, 한 장을 오래 노출하는 단조로움을 막기 위해 아래 동적 연출을 필수 적용합니다.
   - **동적 카메라 워크 기본 적용**: Remotion 렌더링 시 모든 씬에 미세한 줌인/줌아웃 또는 패닝을 기본 적용합니다.
   - **2~2.5초 주기 시각 변화 필수**: 2~2.5초마다 화면 전환 또는 핵심 키워드 강조 애니메이션(팝업·확대·색 강조 등) 중 하나 이상으로 시각적 변화를 반드시 줍니다.
   - *(기존 4.0~4.8초/장 노출 규칙은 위 동적 연출 규칙으로 대체)* (대본 문장 단위로 쪼개져 씬이 과도하게 많아진 경우, 인접한 동일 맥락 씬은 같은 이미지를 공유하거나 씬을 통합해 시청자가 이미지를 충분히 기억할 수 있게 유지합니다.)
3. **Google Flow (`https://flow.google.com/`) 생성 규칙**:
   - 기본 모델: **`Nano Banana Pro`** (`이미지`, `9:16`, `x1`, `0 크레딧` 확인). 일일 Pro 한도 도달 시에만 남은 씬을 `Nano Banana 2`로 진행.
   - **정책 위반 원천 차단(필수)**: 모든 프롬프트(`start_image_prompt`, `video_prompt`)와 시작 프레임 이미지에 **실존 인물·유명인 이름이나 닮은 얼굴 절대 금지**. 항상 귀여운 오리지널 클레이 캐릭터(`a cute original clay scientist character`, `the tiny clay figurine` 등)로 대체.
   - **속도/안정성**: CAPTCHA/자동화 감지 방지를 위해 4~8개 씬 단위 소량 배치로 천천히 생성하고, **`1K 원본 크기`**로 다운로드.
4. **사운드 디자인(BGM & SFX) 필수 규칙**:
   - **SFX 배치**: 초반 3초 훅 진입 시, 그리고 체감형 반전이 터지는 핵심 타이밍에 효과음(SFX)을 반드시 배치합니다.
   - **BGM 믹싱**: 주제 분위기(인체·우주·일상과학)에 맞는 BGM을 선택하고, 나레이션을 방해하지 않도록 **-18dB ~ -22dB** 볼륨으로 믹싱합니다.
5. **최종 렌더링 & 사본 저장**:
   - `final.mp4` 렌더링 완료 후, 같은 프로젝트 폴더에 `<제목>.mp4`(Windows 금지문자 `? * : " < > | / \` 제거) 사본을 반드시 함께 생성.
